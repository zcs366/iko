# 创业人物谱系研究框架 v1.0

## 总纲

> **研究命题**：成功者与"意难平"对照
> **方法**：长编→定本，搜→写→劈
> **风格**：中国古典语言，以正史为本，以《史记》《资治通鉴》为骨干，辅以现代创业研究视角
> **禁忌**：不用现代商业术语污染（禁止"赛道""打法""底层逻辑""抓手""赋能"等词）

## 每对结构模板

每对人物研究笔记统一采用以下八段结构：

1. **一句话对照**——核心矛盾或差异，十字以内为佳
2. **各自出身**——家世、早年经历、性格底色
3. **风云际会**——如何登上历史舞台，初始局面
4. **关键转折**——三到五个决定性节点
5. **胜负析因**——赢者何以赢，输者何以输
6. **意难平**——如果重来会怎样？输家输在哪一口气？赢家赢在哪一手？
7. **对创业者的启示**——三条以内，直指本质
8. **材料来源与延伸阅读**——正史篇目、后世评注、现代研究

## 交叉比较矩阵

除上述14对直接对照外，研究过程中应建立以下交叉视角：

- **项羽线**：项羽 → 拿破仑（P2-12）→ 汉尼拔（P1-6）→ 军事天才的悲剧共性
- **刘邦线**：刘邦 → 朱元璋（P2-11）→ 凯撒（P1-5）→ 布衣/中产出身的权力巅峰
- **合伙人线**：乔布斯/沃兹 → 陈胜/吴广 → 庞培/凯撒 → 合伙如何成就与毁灭
- **创业节点**：起事→扩张→相持→决战→守成，五阶段人物对照

## 研究原则

1. **以正史为锚**：中国人物以二十四史本纪、列传为准；西方人物以权威传记及原始史料为准
2. **不预设立场**：不预设"成功者必有德""失败者必有缺陷"，让材料说话
3. **意难平不是同情**："意难平"是理性分析输赢之间的那层薄膜——不是为输家辩护，而是拆解赢家的运气和输家的必然
4. **对现代创业者有意义**：每对研究的结尾必须提炼可迁移的认知，而非止于历史故事
5. **保持古典文风**：以《史记》行文为范，简洁、有力、有画面感，不用PPT语言
